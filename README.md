# 🧩 Sudoku Solver

A modern, responsive web application that solves Sudoku puzzles with an elegant user interface and smooth animations.

## 🌐 Live 
Check out the live application: [Sudoku Solver](https://sudokusolver1.onrender.com/)

## ✨ Features

- **Interactive Grid**: Beautifully designed 9x9 grid with intuitive input handling
- **Real-time Validation**: Accepts only valid numbers (1-9) as input
- **Animated Solution**: Smooth visualization of the solving process
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Clean Interface**: Minimalist design with a gradient background and modern styling
- **Error Handling**: Clear feedback for invalid puzzles or inputs

## 🚀 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python, Flask
- **Styling**: Custom CSS with responsive design
- **Custom Font**: DreamlandStd for enhanced visual appeal
- **Deployment**: Hosted on Render

## 🎯 How to Use

1. Visit [https://sudokusolver1.onrender.com/](https://sudokusolver1.onrender.com/)
2. Enter numbers (1-9) in the cells to create your Sudoku puzzle
3. Click "Solve" to find the solution
4. Use "Clear" to reset the grid
5. Click "Exit" to close the application

## 💻 Technical Implementation

The project is structured into several key components:

- `app.py`: Flask backend handling routing and puzzle solving
- `index.html`: Main application structure
- `style.css`: Responsive styling and animations
- `scripts.js`: Frontend logic and API interactions

### API Endpoints

- `GET /`: Serves the main application
- `POST /solve`: Accepts a Sudoku board and returns the solution
